# Brief: det-film — The Determinant (40 s · 9:16 + 16:9 · synthesized)

**One line:** by the end the viewer can expand a 3×3 determinant along a row by hand — and feels that
the answer is one number that captures the whole matrix (8 → the box grows to ×8 volume; 0 → flat).

**Inputs:** none (pure typographic + geometric film). No brand, no screenshots.

**Must-haves**
- 2×2 building block: `ad − bc` with animated diagonals (you need it for 3×3)
- 3×3 cofactor expansion: cross out the row + column of each row-1 entry → the 2×2 **minor** peels off
- Alternating signs `+ − +` stamped on row 1
- One worked example, real numbers: **A = [2 1 1 · 1 2 1 · 0 1 3]** → minors 5, 3, 1 → `2·5 − 1·3 + 1·1` → **det(A) = 8**
- Meaning: det = the volume factor (cube → parallelepiped, vol ×8), then det = 0 → space collapses flat
- SFX on every landing; every visual event on the 0.5 s beat grid (120 bpm)

**The running object:** one bracketed matrix that travels through the film (hook → grows from the 2×2 →
crossed out → becomes cards → numbers). The worked example's columns are the same vectors that draw
the volume box in the meaning scene — computation and geometry meet on the same matrix.

**Feel:** an engineering notebook — warm paper, graph-paper grid, ink, one red teacher's pen.
Calm, precise, surprisingly warm piano. Nothing techy, no gradients, no glow.
