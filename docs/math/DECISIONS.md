# Decisions

Format: `D-NNN  date  phase  decision / evidence / consequence` (mirrors `docs/editing/DECISIONS.md`).

**D-001 2026-10-03 P0 — baseline and branch.** `feat/math-videos` branched from `feat/real-video-editing` (which is not merged into `main`; the math work builds on the edit plumbing). `./studio verify-edit --clean` removed 29 leftover `verify-*` temp films from the first mission (~5 GB, the hygiene rule's motivation). Baseline: `./studio regress` PASS on this tree (4 motion films, 8/8 frame hashes + gate verdicts identical; `determinant-explainer` still broken exactly as the editing mission's D-001 records). The human's two untracked files (`templates/prompts/math-video-engine.md`, `run-until-done.sh`) are the mission spec + its supervisor: committed on this branch, never edited.

**D-002 2026-10-03 P0 — verify-math mirrors the editing verifier's conventions (their D-003/D-004).** Results `docs/math/verify-last.json` written only by a full run; `--only` writes `verify-last-only.json`; `--quick` writes `quick:true` and can never pass (skipped-because-quick counts as not passing); a check with no implementation file is `pending` = red; a `skip` is honest only for an environment cause. Checks live in `engine/verify/math/<id>.mjs` (default export `async (ctx) => { pass, measured, skip? }`); the runner owns the table; later phases add files, never edit the runner's semantics. Own lock `math-verify.lock` (separate from verify-edit's): a full `verify-edit` running concurrently makes this runner's `regress` check fail loudly with the lock's message instead of silently skipping — full runs are sequential by design (verify-math first, then the background verify-edit; the mission's final sequence follows that order).

**D-003 2026-10-03 P0 — the `regress` check spawns the CLI, and its position in the table is part of the contract.** `regress` runs `node engine/cli.mjs regress` and `node engine/cli.mjs verify-edit --only env,edit-ops,gui-security,tools,docs` as subprocesses rather than importing the check functions, so the lock, temp-film sweep and row printing are exactly the user's. The spawned verify-edit's `cleanTemp` removes any `films/verify-m-*` older than its own start — so `regress` must run before any check that creates temp films (it is check #2, after `env` which creates none). Reordering CHECKS to put a film-creating check before `regress` would let the spawned verify-edit delete mid-run fixtures: don't. The `--only` exit code is non-zero by design (a partial run can never pass), so the check reads its five rows (`PASS` x 5), not the exit code.

**D-004 2026-10-03 P0 — the `slow` set is a first guess.** Slow (skipped by `--quick`): `render-determinism`, `formats`, `scene-cache`, `concat-mux`, `perf-budget`, `library`, `starter`, `demos` — the checks that inherently render or ship. Everything else runs in `--quick` (target <= 5 min), including `regress` (~2.5 min: 65 s `studio regress` + the five cheap edit checks) — the no-regression guarantee must hold on every run. Calibrate against both budgets (5 min quick / 60 min full) as phases land; freeze with the S4 numbers. Changing a `slow` flag later needs a DECISIONS entry with the measured runtimes.

**D-005 2026-10-03 P0 — `verify-math --clean` and the end-of-run sweep remove all stale `verify-*` films, not only `verify-m-*`.** The mtime guard (films older than this process's start − 2 s) is kept, so a concurrently-created film is never touched: each check cleans its own, the sweep is the backstop for crashes and for the first mission's leftovers (hygiene check: after a full run `films/` holds no `verify-*`).

**D-006 2026-10-03 P2 — the typeset.py OOM (found by reading, fixed by rewrite).** The first `_emit_labels` ran `while "{{" in out:` but only reassigned `out` in a `for` AFTER the loop — the condition never became false, `labels`/`auto` grew without bound, and any `Eq` containing a `{{label}}` OOM-killed the process (twice, thrashing the whole WSL system). Rewrite: `_split_labels` is a single forward pass (`pos = end + 2` — strictly advancing, provably terminating) and labels are PIECEWISE: each segment converts on its own and the label emits as MathTypst's `{{ converted : name }}` — no control-character placeholders at all (the old design smuggled labels through conversion via NUL/SOH markers, which tex2typst could have mangled anyway). Also fixed `font_path` (a `parents[N]` index pointed at Desktop/, then engine/manim/; it now walks up until the directory that actually contains `fonts/` — self-verifying) and the font-size contract (`PT_PER_U = 48/9`, calibrated: 48pt ≈ the 9u math role). Acceptance (`~/.cache/pi-motion-studio/scratch/leak-accept.py`, run under the 1 GB systemd cgroup cap): all 11 steps pass, peak 161 MB. **Every Python/manim test process now runs under `~/.cache/pi-motion-studio/scratch/cap` (systemd MemoryMax=1G, no swap, nice'd); the M4 runner enforces the same.**

**D-007 2026-10-03 P2 — the structural memory guard (`engine/lib/capped.mjs`).** After D-006, "never again" is code, not care: every Python/Manim process the studio spawns goes through `runCapped`/`MemPool` — a systemd user-cgroup hard cap (MemoryMax, MemorySwapMax=0) with an RSS process-group watchdog as the second belt (machines without systemd get the watchdog alone), a wall-clock SIGKILL budget, the deterministic env (PYTHONHASHSEED=0, C.UTF-8, SOURCE_DATE_EPOCH, PYTHONDONTWRITEBYTECODE), and a total-RAM scheduler where a job declares its expected peak (= its cap) and the queue NEVER lets the running sum exceed 4608 MB of this 6.8 GB box. Caps (calibrated in ADR-004, raise only with a new DECISIONS entry + measurement): check 1024 MB (measured dry-run ~200 MB), draft 1536 MB (measured ~920 MB), final 3072 MB (measured heavy-scene 3.16 GB — a scene that hits it is KILLED LOUDLY and gets split, never "given more"). A cgroup OOM kill is attributed (`reason: 'memory'`) so the error names the scene and its last animation. Self-test (`/tmp/capped-selftest.mjs`, committed as `engine/manim/test/capped-selftest.mjs`): all six guards pass — a 1.4 GB alloc under a 700 MB cap dies in 0.73 s, a normal process completes, a hung one dies at budget, the env carries, the pool runs 2800 MB of jobs without oversubscribing.

**D-008 2026-10-03 P2 — Manim's frame is CENTERED at (0,0); the Canvas convention cost the first render.** The first `every-16x9` sheet showed everything crammed top-right, half off-frame: `layout.py` had computed boxes as if the origin were bottom-left (0..W × 0..H — the Canvas engine's convention), but Manim's origin is the frame CENTER (x ∈ [-W/2, +W/2]). The fix is the convention itself, documented in `layout.py`'s docstring and carried by every box (`left/right/bottom/top` are now explicit attributes). Caught by LOOKING (the mission's loop, working as designed: 4 look-fix rounds on the starter so far).

**D-009 2026-10-03 P2 — kit layout rules born from the starter's sheets.** (1) `Txt` NEVER exceeds the safe width: it scales to fit (the portrait title ran off both edges at the ×1.3 portrait multiplier). (2) PORTRAIT type multiplier (math/body ×1.5, title ×1.3) — u is a fraction of the SHORT side, so identical u fills a much smaller share of a tall frame; the Canvas det film did this by hand ("15u matrix, 11u formula"), the kit does it by rule, floors still enforced by the lint. (3) Stacks chain with `next_to` (measured heights) and the group centers in the stage — a guessed step made the portrait matrices collide. (4) A plane is SIZED FROM L (`x_length/y_length`), never left at Manim's default span (the 9:16 parallelogram clipped the right edge). (5) MathTex/Typst mobjects default to WHITE: `Eq` colors with the theme's ink by default. (6) Text-used math roles carry INK-grade colors (#A86400/#C0452B/#7A4E00), fills keep the light palette — the fill-grade amber measured ~2:1 on cream at phone size.

**D-010 2026-10-03 P3 — lint semantics (worker-built, verified).** Overlap = axis-aligned interpenetration > 0.05u on both axes (the solver keeps a 0.05u gap, so solved layouts are lint-clean by construction). allow_pairs match by kind, role or "text", unordered; the DEFAULT allow set is text-over-furniture: NumberPlane, Axes, Grid, NumberLine (every Canvas film label sits on the grid; a plane is the page, not a figure) — text over real shapes (Polygon, Square, gnomons, plotted curves) stays a violation. Planes/axes/grids are exempt from offscreen (they may bleed past edges). `tick` labels don't count toward density (an axis has many). Frame/safe edge within 0.01 counts inside (records round to 3 decimals). A null nominal_u skips the size rule (no height_u fallback). Density reports at WARN. The real-render leg runs in --quick (one draft scene, ~5 s — not in the slow set).
**D-011 2026-10-03 P4 — claims semantics (worker-built, verified).** A single top-level comparison is decided side-by-side: `==` is exact (matrices entry-by-entry, shapes must match; symbolic sides via simplify(lhs-rhs)==0; `tol=` means |N(lhs-rhs)| <= tol, and exact is the default). <, <=, >, >= use sympy's comparison; undecided (e.g. x**2 >= 0) is ValueError, never false. Non-statements raise. Syntax is checked before eval; unparseable claims land in the ledger `ok:null` with an error field — gates treat anything but ok===true as failure. draft mode: state "claims_mode":"record" records-and-continues (M2), strict is the default and math.mjs never sets the key. `--independent` = one fresh process per claim (48/48 agree, ~1.5 s each; the process also imports manim via the package __init__ — a known cost, noted for a later lazy-import pass). The coverage word list (incl. "is"/"are") makes nearly every narrated sentence "mathematical" — revisit against the demos' ≥90% bar in P12.
**D-012 2026-10-03 P3/P4 — ManimColor.to_hex(), not .hex.** The recorder's color lookup returned null for every text object (the contrast rule never ran on real records): this Manim's ManimColor has no `.hex`. Fixed to `to_hex()`; verified on fresh mathdemo records (Txt #000000, Eq #17150F, "all text colored: true") and the layout-lint check now reports "0 without color".

**D-013 2026-10-03 P2 — math drafts get their color tags from the frames (worker-found, verified).** ffmpeg 8 ignores the `-color_*` output flags (primaries/transfer stayed `unknown`, SAR N/A) — the mux now stamps them via `setsar=1` + `scale=in_color_matrix=bt601:out_color_matrix=bt709` + `setparams`, the same approach as render.mjs, WITH the real 601→709 conversion (a bare retag measurably shifted ink #C0452B to (202,78,38); the conversion keeps (188,65,39) vs (191,67,41) decoded direct — the formats check fails without it in all four geometries).
**D-014 2026-10-03 P2 — render-derived writes are not source edits.** Writing the synced duration into film.json preserved its mtime — otherwise every draft looked stale and every `look` re-rendered (the look check caught it on its first run). `draftStale` also watches `timing.json` and `engine/math.mjs`.
**D-015 2026-10-03 P2 — geometry fractions are measured from the TOP of the frame.** Manim's y points UP; `(y+4)/8` measures from the bottom (the D-008 convention mistake in a new disguise) and would score a correctly-top title ~0.85. The formats check measures `(H/2 - y)/H`: real title at 0.14 (16:9) vs 0.23 (9:16) — different fractions = a re-composition, not a scaled copy.
**D-016 2026-10-03 P5 — the narration timing contract (worker-built, verified).** Sentences play in script order with a 0.15 s gap rounded to whole samples; `start_sample` + `samples` stored so the mix places audio exactly. A bookmark's `t` is seconds FROM ITS SENTENCE'S START (how `StudioScene.at()` reads it); sentence `start`/`end` are film seconds. Word times come from edit-distance phoneme alignment (espeak merges "on the" — counting words was wrong 1-in-17); <60% phoneme match falls back to proportional + flagged. Voice cache key = sha256(voice, spoken, post-lexicon text, length_scale, voice.py sha) — a lexicon edit re-voices only what it changes. Hyphenated respellings are lower-cased (espeak reads "TUR" letter-by-letter). Human narration: ASR words aligned by word-level edit distance, sentence starts snapped to the speech onset after the longest pause within −0.3..+0.6 s (unsnapped: 130–393 ms early; snapped: 8–20 ms). Mix extends to narration end + 0.5 s (never cuts speech) and warns.
**D-017 2026-10-03 P5 — the starter lexicon's "determinant" respelling hurt the voice (measured: WER 4.7% with vs 2.3% without; every extra error was "determinant" mis-heard).** Removed; espeak's own pronunciation wins. The lexicon keeps genuinely-hard names (Euler OY-ler, Cauchy koh-SHEE, gnomon NOH-muhn, eigenvector, …). fa films with no explicit voice now default to piper:fa_IR-amir-medium (the template's en voice used to leak into fa scaffolds). The `voice` check's clause-3 fixture keeps its own lexicon and is unaffected.

**D-018 2026-10-03 P5 — D-016 amendment: narration.mjs wrote FILM-time bookmark t (the wave-1 worker found it: voice.mjs:101 had locked the bug in; look --mode bookmarks clamped at 11.2+14.6). **D-019 2026-10-03 P5 (orchestrated takeover — both wave-2 claude workers died on the account rate limit) — the scene clock.** `say()/at()/until()` are real: the scene's local zero is its FIRST sentence's film start (derived, never stored); entering a sentence SEEKS (wait) to its local start if animations ran short; exiting PADS to its end; overruns are never rewound — an `overrun` trace entry records the excess (the sync check surfaces it). `say(id)` VALIDATES: an unknown id or a sentence belonging to another scene is a hard ValueError naming the known sentences (it caught the scene-cache fixture's own 3-sentence script immediately). `at()` stamps a `bookmark` trace entry {id, t, sentence} — the sync check's ground truth. Only the scene's OWN sentences are read (the cache contract). Without timing data (check runs) the context is a pass-through. Measured: voiced mathdemo = 20.83 s both formats (was 14.2 silent), bookmarks at real film times (shows@2.937, lands@14.615), one honest overrun recorded in s02.

**D-020 2026-10-03 P6 — the scene cache (§3.8).** Content-addressed per (scene source, every studio_manim module, design, film cfg minus duration, fmt/quality/fps/px, manim version, the scene's REBASED timing slice, the 0.15 s gap). REBASED slice = ids/text/spoken/durations/word-times-relative-to-sentence/bookmarks as written — absolute film times shift with upstream edits but change nothing a scene draws, so an s01 sentence edit re-renders ONLY s01 (later scenes keep their keys; the concat absorbs the shift). `noCache` bypasses (render-determinism's "cold" pair must not hit it — its scratch-only wipe would make the second render a vacuous md5 match). Cache writes are tmp-dir + rename (a partial entry is never served). Returns {rendered, cached} for the check's assertions.
