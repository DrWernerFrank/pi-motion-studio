# chart tools (K12)

The tool surface this capability declares. The lead wires these into .pi/extensions (a
Type.Object schema each, same style as tools.ts, listed in index.ts BY_FILE); a capability with
no tools yet still lists its intended ones here so the contract stays visible. The growth check
asserts at least one tool entry line:

- `chart_status` — read the chart film's status: the kind, its parts, the summary of its own data files
- `chart_check` — run this technique's own gates on a film and report the FAIL lines
